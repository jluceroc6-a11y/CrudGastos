Proyecto CRUD de Gastos

Descripción

Este proyecto consiste en un programa hecho en C# que permite registrar y administrar gastos utilizando una base de datos en SQL Server llamada "GastosBD".

¿Qué puede hacer el programa?

El programa cuenta con un menú de seis opciones que permite:

1. Registrar un gasto.
2. Listar los gastos registrados y mostrar el total gastado.
3. Buscar un gasto por su ID.
4. Actualizar el monto de un gasto.
5. Eliminar un gasto.
6. Salir del programa.

También se agregaron validaciones para evitar ingresar montos incorrectos y un manejo de errores para que el programa no se cierre si ocurre un problema con la base de datos.

Herramientas utilizadas

- C#
- Visual Studio
- SQL Server
